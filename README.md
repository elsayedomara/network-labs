# Networking Labs

A collection of practical networking labs and exercises focused on building strong foundations in computer networking and network security.

## About

This repository documents my practical learning journey in **Networking & Information Security**.

The labs cover networking concepts, protocols, troubleshooting, and security fundamentals through hands-on exercises.

## Topics Covered

- Network Fundamentals
- TCP/IP
- OSI Model
- IPv4 & IPv6
- Subnetting
- DHCP & DNS
- Network Troubleshooting
- Cisco Networking Fundamentals
- Network Security Fundamentals
- Linux Networking

## Lab Structure

Each lab contains:

- Objective
- Network concept
- Configuration / practical steps
- Results
- Notes and observations

## Learning Goals

- Build strong networking fundamentals
- Improve network troubleshooting skills
- Understand how common network protocols work
- Develop practical network security knowledge
- Document hands-on learning and experiments
